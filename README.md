### 🍺 02. Beer ABV Prediction | Deep Learning (PyTorch)
**Status:** `🟢 UKOŃCZONO` | **Folder:** [`/BEER`](./BEER/)
* **Opis:** Sieć neuronowa typu **MLP (Multi-Layer Perceptron)** do przewidywania zawartości alkoholu (ABV) w piwie.
* **Kluczowe cechy:**
    * Regresja na danych z Kaggle przy użyciu frameworka **PyTorch**.
    * Architektura: 2 warstwy ukryte (32 i 16 neuronów) z aktywacją **ReLU**.
    * Automatyczne generowanie krzywych utraty (Loss Curve) i wykresów regresji.
* **Technologie:** PyTorch, Pandas, Scikit-learn.
